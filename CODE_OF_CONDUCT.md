# Code of Conduct

## Our Pledge

We are committed to making participation in this project a harassment-free experience.

## Standards

- Using welcoming and inclusive language
- Being respectful of differing viewpoints
- Gracefully accepting constructive criticism
- Focusing on what is best for the community

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, code, wiki edits, and issues that do not align with this Code of Conduct.
